# Od promptu k produktu

Interaktivní web o mé cestě s AI (česky a anglicky).

- `index.html` – celá stránka včetně stylů a skriptu
- `img/` – anonymizované ukázky
- `audio/podkres.mp3` – hudební podkres, spouští se jen tlačítkem
- `robots.txt` a značka `noindex` v `index.html` – web nemá být indexován ani procházen roboty

Web je statický, nepotřebuje žádné sestavení. Stačí zapnout GitHub Pages z větve `main` (kořenová složka).
